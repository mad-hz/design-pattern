# Console-Based Chatbot Application
### Project Overview
This project is a console-based chatbot application developed in Java.
The chatbot interacts with users through text input, responds to basic commands, and exits gracefully when requested. The application has a single, clear purpose: to simulate a simple conversational agent via the command line.
The project is designed incrementally. A basic working chatbot skeleton was implemented first, after which design patterns are introduced to improve structure, extensibility, and maintainability.
